# AdonisJS + Shadcn Vue Starter Kit

An unofficial starter kit for building production-ready applications with the VISA (Vue + Inertia + Shadcn + Adonis) stack.

# Tech Stack

<table>
  <tr>
    <td>Backend</td>
    <td><a href="https://adonisjs.com">Adonis.</a> A backend-first batteries-included type-safe framework.</td>
  </tr>

  <tr>
    <td>Frontend</td>
    <td><a href="https://vuejs.org">Vue.</a> An approachable performant and versatile framework for building web user interfaces.</td>
  </tr>

  <tr>
    <td>Bridge</td>
    <td><a href="https://inertiajs.com">Inertia.</a> A modern monolith approach to building single-page applications with server-side routing.</td>
  </tr>

  <tr>
    <td>Components</td>
    <td><a href="https://shadcn-vue.com">Shadcn.</a> A collection of beautifully designed accessible customizable components.</td>
  </tr>
</table>

# Installation

## Initialize the project

```bash
npm init adonisjs@latest -- -K="doguozcan/adonisjs-shadcn-vue-starter-kit"
```

## Navigate to the project directory

```bash
cd adonisjs-app
```

## Start the development server

```bash
node ace serve --hmr
```

Your application is available at http://localhost:3333.
